## 0. 한 줄 방향

> **사진이 말하고, 글자는 Serif 로 조용히 거든다.**

v1과 달라진 것은 "사진집"이라는 기준 자체가 아니라 **판형**이다.
v1은 폰 한 손 폭(640px) 안에 한 줄씩 쌓는 세로 사진집이었다.
v2는 **펼친 여행 잡지**다 — 폭 1200px, 사진이 여러 장 나란히 놓이고, 크림색 종이 위에 Serif 제목이 앉는다.

기준이 되는 느낌: **잘 만든 여행 잡지의 특집 기사**. 앱 화면이 아니다.

- 배경은 순백이 아니라 **크림**(`#F5F3EC`)이다. 종이에 가깝다.
- 제목은 전부 **Serif**(Source Serif 4)다. 본문만 Sans 다.
- 강조는 **솔잎 그린 하나**뿐이고, 색을 채우는 건 사진이 한다.
- 그림자는 여전히 **없다.** 깊이는 사진과 바탕색 단계로만 만든다.

## 1. v1에서 바뀐 것 (요약)

| 항목      | v1                                   | v2                                            |
| --------- | ------------------------------------ | --------------------------------------------- |
| 배경      | 순백 `#FFFFFF`                       | 크림 `#F5F3EC` + 종이 3단계                   |
| 제목 폰트 | Bricolage Grotesque                  | **Source Serif 4**                            |
| 본문 폰트 | IBM Plex Sans + IBM Plex Mono        | **Source Sans 3** 하나 (Mono 폐지)            |
| 강조색    | 쪽빛 `#1F4E5F`                       | 솔잎 그린 `oklch(0.38 0.06 150)`              |
| 모서리    | 전부 4px                             | 3·4·6·8px + 알약(999px)                       |
| 내용 폭   | 640px 한 줄                          | **1200px**, 카드 2~4열                        |
| 그라데이션 | 전면 금지                            | **사진 자리에만** 허용 (photos.md §3-5)       |
| 그림자    | 없음                                 | 없음 (그대로)                                 |
| 별점 ★    | english_ease·localness 를 별로 표시  | 폐지 — 문장으로 적는다 (patterns.md 14번)     |
| 흐름      | 질문 3단계 → 결과 → 이메일 수집      | 둘러보기 → 저장 (이메일 수집 폐지)            |

흐름이 바뀐 이유는 `structure.md` §1-2 에 적어 두었다.
