## 3. 사진 규칙 (가장 중요)

### 3-1. 이 사이트의 핵심 장치: 사진 캡션

**모든 사진 아래(또는 위)에 Mono 글씨로 "장소 · 시간"을 적는다.**

```text
Jumunjin, Gangneung · 05:40
Daegwallyeong · after rain
Anmok Beach · 06:10, Nov
```

이게 이 사이트가 다른 여행 사이트와 달라 보이게 만드는 단 하나의 장치다.

- 사진이 스톡 사진이 아니라 **실제로 그 시간에 거기 있었다**는 증거처럼 보인다.
- "언제 가야 하는가"라는 정보를 장식이 아니라 사진 자체가 전달한다.
- 관광 사이트는 캡션을 안 쓴다. 사진집과 기행문은 쓴다.

규칙:

- 형식: `장소 · 시간/계절/상황`. 두 칸을 넘지 않는다.
- 시간을 모르면 계절이나 상황(`after rain`, `market day`)을 쓴다. 비워 두지 않는다.
- 글자 크기 `text-caption`, 색은 `ink-soft`. 사진 위에 얹을 때는 흰색.

### 3-2. 어떤 사진을 쓰나

**쓰는 사진**

| 종류                                        | 예시                                      |
| ------------------------------------------- | ----------------------------------------- |
| 한국의 실제 장소, **특정 시간의 특정 순간** | 주문진 어시장 새벽 5시 40분, 손님 오기 전 |
| 사람이 작게 들어간 풍경                     | 대관령 능선 위 걷는 사람 한 명            |
| 날씨가 있는 사진                            | 안개, 비 온 뒤, 겨울 바다, 역광           |
| 서울에서 못 보는 것                         | 산 능선, 동해, 시골 장, 밤의 항구         |
| 손과 음식이 가까이 찍힌 것                  | 어시장 좌판, 순두부 한 상                 |

**안 쓰는 사진**

| 종류                                                      | 왜                                                          |
| --------------------------------------------------------- | ----------------------------------------------------------- |
| AI로 만든 사진                                            | 손·글자·창문이 이상하고, 사람들이 알아본다. 신뢰가 무너진다 |
| 관광공사 홍보 사진 느낌 (햇빛 쨍쨍, 채도 과함, 정면 구도) | 어디서나 본 사진. "진짜 한국"과 반대                        |
| 스톡 사진 특유의 미소 짓는 외국인 모델                    | 광고처럼 보인다                                             |
| 드론 항공샷만 있는 것                                     | 실제로 갈 때 보이는 풍경이 아니다                           |
| 과하게 보정한 것 (HDR, 채도 올림, 하늘 색 갈아 끼움)      | 갔다가 실망한다 = PRD가 풀려는 문제와 반대                  |
| 서울 야경, 광화문, 한복 입은 뒷모습                       | 이미 다들 봤고, "Seoul is 1%"와 모순                        |

**사진 출처 우선순위**

1. 직접 찍은 것 (쇼츠 찍을 때 사진도 같이 찍는다)
2. 팔로워가 보내 준 것 (이름 표기)
3. 무료 사진 (Unsplash 등) — 위 "안 쓰는 사진" 기준에 맞는 것만. 출처는 상세 페이지 맨 아래 작은 글씨로

### 3-3. 사진 크기·비율

| 어디                  | 비율             | 이유                                                           |
| --------------------- | ---------------- | -------------------------------------------------------------- |
| 첫 화면               | 화면 전체 (세로) | 폰을 세로로 들었을 때 사진이 화면을 다 채워야 한다             |
| 결과 카드             | **4:5** (세로)   | 폰에서 가장 크게 보이는 비율. 인스타 게시물 비율이라 눈에 익다 |
| 상세 페이지 맨 위     | 4:5              | 카드에서 그대로 커진 느낌                                      |
| 상세 추가 사진        | 3:2 (가로)       | 2~3번째 사진은 가로로 리듬을 바꾼다                            |
| 작은 카드 (관련 경험) | 1:1              | 작을 땐 정사각형이 정보 밀도가 좋다                            |

- 사진은 **잘라서 맞춘다** (object-fit: cover). 여백을 넣거나 늘리지 않는다.
- 폰 기준 카드 사진 폭 = 화면 폭 − 32px. 파일은 폭 1200px 이면 충분. WebP.
- 사진이 로딩되는 동안: 회색 네모(`line` 색). 흐릿한 미리보기, 반짝이는 효과 없음.

### 3-4. 사진 위에 글자를 올릴 때 (첫 화면만)

- 반투명 검은 막을 **씌우지 않는다.**
- 대신 사진을 고를 때 **아래쪽 1/3이 어둡거나 단순한 사진**을 고른다 (바다, 그림자, 안개).
- 글자에 아주 약한 그림자만 준다: `0 1px 2px rgba(0,0,0,0.3)`. 이건 "그림자 없음" 규칙의 유일한 예외다.
- 그래도 안 읽히면 사진을 바꾼다. 글자에 배경 상자를 넣지 않는다.
