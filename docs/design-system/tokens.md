> 목차는 `index.md`. 실제 값은 `src/app/globals.css` 의 `@theme` 에 있다 — 둘이 다르면 이 문서를 기준으로 고치고, 다르다는 사실을 알린다.

## 2. 디자인 기본 규칙

### 2-1. 색

원칙: **색은 세 무리뿐이다.** 종이(바탕), 먹(글자), 강조 하나. 나머지 색은 전부 사진이 낸다.

**종이 — 바탕**

| 이름      | 값        | 어디에                                    |
| --------- | --------- | ----------------------------------------- |
| `paper`   | `#F5F3EC` | 모든 화면의 배경                          |
| `paper-2` | `#F0EDE4` | 구역 배경 (첫 화면 시즌 밴드, 하루 흐름)  |
| `paper-3` | `#ECEADE` | 상자 배경 (정보 칸, breadcrumb 띠, 숫자)  |
| `surface` | `#FAF9F3` | 테두리가 있는 카드 안쪽, 입력 칸          |

> `surface` 를 `card` 로 부르지 않는다. Tailwind 의 `text-*` 는 `--color-*` 와 `--text-*` 를 둘 다 보기 때문에 `--color-card` 와 `--text-card` 가 있으면 `text-card` 가 글자 크기가 아니라 색으로 잡힌다.

**먹 — 글자**

| 이름       | 값        | 어디에                               |
| ---------- | --------- | ------------------------------------ |
| `ink`      | `#1C1B18` | 제목, 기본 글자, 고른 알약의 배경    |
| `ink-2`    | `#3D3C36` | 본문 설명 글                         |
| `ink-soft` | `#55544D` | 카드 한 줄 설명, 보조 안내           |
| `ink-mute` | `#7A786E` | 눈썹 글자(eyebrow), breadcrumb       |

**선**

| 이름          | 값                      | 어디에                          |
| ------------- | ----------------------- | ------------------------------- |
| `line`        | `rgb(28 27 24 / 0.12)`  | 구분선, 카드 테두리, 구역 나눔  |
| `line-strong` | `rgb(28 27 24 / 0.30)`  | 보조 버튼 테두리, 입력 칸, 알약 |

**강조 — 솔잎 그린 하나**

| 이름             | 값                      | 어디에                              |
| ---------------- | ----------------------- | ----------------------------------- |
| `accent`         | `oklch(0.38 0.06 150)`  | 큰 버튼, 번호 동그라미, 저장 표시   |
| `accent-press`   | `oklch(0.32 0.06 150)`  | 눌림·마우스 올림, 강조 글자 링크    |
| `accent-soft`    | `oklch(0.92 0.02 150)`  | 밴드 배경, 상세 페이지 오른쪽 상자  |
| `accent-soft-2`  | `oklch(0.87 0.03 150)`  | 태그 알약 배경                      |

**그 밖**

| 이름             | 값                       | 어디에                    |
| ---------------- | ------------------------ | ------------------------- |
| `error`          | `#B4382A`                | 오류 문구에만             |
| `on-photo`       | `#FFFFFF`                | 사진 위 글자              |
| `on-photo-soft`  | `rgb(255 255 255 / 0.6)` | 사진 안 캡션              |

**쓰면 안 되는 것**

- 강조색 2개 이상. 그린 말고 다른 강조를 새로 만들지 않는다.
- 보라, 밝은 파랑, 민트, 네온 계열.
- 버튼·글자·상자에 넣는 그라데이션. 그라데이션은 **사진 자리에만** 쓴다 (photos.md §3-5).
- 그림자. 어디에도 없다. `accent-soft` 같은 바탕색 단계로 깊이를 만든다.

### 2-2. 글자

| 역할        | 폰트                | 이유                                                  |
| ----------- | ------------------- | ----------------------------------------------------- |
| 제목 전부   | **Source Serif 4**  | 잡지 특집 기사의 목소리. 600·700 두 굵기만 쓴다       |
| 본문·버튼   | **Source Sans 3**   | 400·500·600. 영어·스페인어·프랑스어를 다 갖고 있다    |

- `h1`·`h2`·`h3` 는 `globals.css` 의 base 층에서 이미 Serif 600 이다. 화면에서 `font-display` 를 다시 적지 않는다.
- 제목이 아닌데 Serif 로 쓰는 자리는 **딱 두 곳**: 제목 밑 한 줄(`text-lead`), 빈 상태 문구.
- 한 화면에 굵기는 **400 + 600** 두 개까지. 700은 로고에만.
- 첫 글자만 대문자(Sentence case). 전부 대문자는 눈썹 글자와 사진 캡션만.

**크기 단계** (폰 기준. 표의 "PC" 는 `md:` 이상에서만 쓴다)

| 이름           | 크기 / 줄간격 | 자간     | 어디에                          |
| -------------- | ------------- | -------- | ------------------------------- |
| `text-hero`    | 60 / 1.08     | -0.015em | 첫 화면 `h1` (PC 전용)          |
| `text-display` | 44 / 1.1      | -0.015em | 페이지 `h1`, 큰 구역 제목       |
| `text-title`   | 34 / 1.15     | -0.01em  | 구역 제목                       |
| `text-section` | 26 / 1.2      | -0.01em  | 상자 제목, 본문 소제목          |
| `text-card`    | 21 / 1.25     | 기본     | 카드 제목                       |
| `text-lead`    | 20 / 1.45     | 기본     | 제목 밑 한 줄 (Serif)           |
| `text-body`    | 16 / 1.65     | 기본     | 본문                            |
| `text-small`   | 14 / 1.5      | 기본     | 한 줄 설명, 버튼, 머리 칸       |
| `text-meta`    | 13 / 1.45     | 기본     | 화살표 링크, 보조 정보          |
| `text-caption` | 12 / 1.4      | 기본     | breadcrumb, 태그 알약           |
| `text-eyebrow` | 11 / 1.3      | 0.14em   | 카드 위 분류 (대문자)           |

- 사진 안 캡션은 10px·자간 0.08em 으로, 부품(`PhotoFrame`) 안에 붙박이다. 토큰으로 빼지 않는다.
- 폰에서 `text-hero` 는 쓰지 않는다. 첫 화면 `h1` 은 `text-4xl md:text-hero`.

### 2-3. 여백

기준 단위는 Tailwind 기본 4px 스케일을 그대로 쓴다.
여백에는 따로 이름을 붙이지 않는다 — 잡지 판형에서는 구역마다 필요한 값이 달라
이름표 몇 개로 묶으면 오히려 맞지 않는 값을 쓰게 된다.

자주 쓰는 값만 적어 둔다.

| 쓰임                | 값                                 |
| ------------------- | ---------------------------------- |
| 글자 사이 좁은 틈   | `gap-2` (8px), `gap-2.5` (10px)    |
| 카드 안 줄 간격     | `mt-1.5`~`mt-4` (6~16px)           |
| 카드와 카드 사이    | `gap-6`~`gap-7` (24~28px)          |
| 구역과 구역 사이    | `pt-11`~`pt-14` (44~56px)          |
| 상자 안 여백        | `px-7 py-7.5` / `px-8 py-9`        |

**화면 좌우 여백**은 `gutter` 유틸리티 하나로 통일한다 (`globals.css` 에 정의).

```text
폰  20px
PC  44px  (48rem 이상)
```

내용 최대 폭은 `max-w-content` = **1200px**. 글만 있는 페이지(개인정보 안내)는 `max-w-[68ch]`.

### 2-4. 모서리·테두리·그림자

| 항목   | 규칙                                                            |
| ------ | --------------------------------------------------------------- |
| 모서리 | 사진 `3px`(`rounded-sm`) · 큰 사진 `4px`(`md`) · 버튼·카드 `6px`(`lg`) · 상자·밴드 `8px`(`xl`) |
| 알약   | 필터 칩, 태그는 `rounded-full`. 이 둘 말고는 알약을 쓰지 않는다 |
| 원형   | 저장 단추(밝은 형)와 하루 흐름 번호만 `rounded-full`            |
| 테두리 | 1px. 색은 `line`, 누를 수 있는 것은 `line-strong`               |
| 그림자 | **없음.** 어디에도                                              |

12px 이상으로 둥글게 하지 않는다 — "앱 템플릿"처럼 보인다. 8px가 상한이다.

### 2-5. 아이콘

- 전부 선 아이콘. 굵기 `1.4~1.6`, 선 끝 둥글게, 색은 `currentColor`.
- 모아 두는 곳은 `src/components/ui/icons.tsx` 한 곳뿐이다. 화면 안에 `<svg>` 를 직접 쓰지 않는다.
- 쓰는 자리: 화살표(링크·버튼), 책갈피(저장), 정보 칸 4종, 취향 칩 6종. 그 밖에는 글자로 해결한다.
- **이모지는 어디에도 쓰지 않는다.**
