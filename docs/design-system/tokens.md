## 2. 디자인 기본 규칙

### 2-1. 색

원칙: **색은 4개면 충분하다.** 사진이 이미 색을 다 갖고 있다.

| 이름    | Tailwind 이름 | 값        | 어디에 쓰나                                    |
| ------- | ------------- | --------- | ---------------------------------------------- |
| 종이    | `paper`       | `#FFFFFF` | 모든 배경. 순백. 크림색 아님                   |
| 먹      | `ink`         | `#1C1C1A` | 제목, 본문, 큰 버튼 배경                       |
| 먹-흐림 | `ink-soft`    | `#6B6B66` | 설명 글, 캡션, 안내 문구                       |
| 선      | `line`        | `#E6E4DF` | 카드 테두리, 표 줄, 입력 칸 테두리             |
| 강조 (지금은 쪽빛) | `accent` | `#1F4E5F` | **강조 딱 하나.** 선택된 버튼, 링크, ★ 채운 별 |

토큰 이름은 색이 아닌 **역할**로 짓는다. 강조색 값이 바뀌어도 `accent` 는 그대로 쓴다.

쪽빛(`#1F4E5F`)을 고른 이유: 동해 새벽 바다 색이다. 파랑이지만 채도가 낮아 "앱 파랑"으로 보이지 않는다. 사진 어디에 놓아도 싸우지 않는다.

**쓰면 안 되는 것**

- 그라데이션 (배경, 버튼, 글자 전부)
- 보라, 밝은 파랑, 민트, 네온 계열
- 크림·베이지 배경 (`#F4F1EA` 같은 것) + 주황·테라코타 강조 조합 → 요즘 AI가 만든 사이트의 대표 조합
- 강조색 2개 이상

**사진 위 글자**: 사진이 밝으면 먹색, 어두우면 흰색. 반투명 막은 씌우지 않는다. 글자가 안 읽히면 **사진을 바꾸거나 글자 위치를 옮긴다.** (사진 고르는 기준은 3-2 참고)

### 2-2. 글자

| 역할           | 폰트                                      | 이유                                                              |
| -------------- | ----------------------------------------- | ----------------------------------------------------------------- |
| 제목           | **Bricolage Grotesque** (구글 폰트, 무료) | 살짝 개성 있는 고딕. 사진 옆에서 존재감은 있되 소리 지르지 않는다 |
| 본문·버튼      | **IBM Plex Sans** (무료)                  | 어디서나 잘 읽힌다. 영어·스페인어·프랑스어 다 있다                |
| 캡션·정보·숫자 | **IBM Plex Mono** (무료)                  | 사진집 캡션, 여행 기록 같은 느낌. "어디 · 몇 시"를 적을 때        |

Inter, Roboto, Poppins는 쓰지 않는다. 너무 흔해서 어디서 본 사이트처럼 보인다.

**크기 단계** (폰 기준. PC는 제목만 한 단계 키운다)

| 이름      | Tailwind       | 크기 / 줄 간격 | 굵기           | 어디에                         |
| --------- | -------------- | -------------- | -------------- | ------------------------------ |
| 대제목    | `text-display` | 40px / 44px    | 600            | 첫 화면 문구, 질문             |
| 제목      | `text-title`   | 26px / 32px    | 600            | 상세 페이지 제목, "Your Korea" |
| 카드 제목 | `text-card`    | 19px / 24px    | 600            | 카드 이름                      |
| 본문      | `text-body`    | 16px / 26px    | 400            | 소개 글, 설명                  |
| 작은 글   | `text-small`   | 14px / 20px    | 400            | 한 줄 설명, 안내 문구          |
| 캡션      | `text-caption` | 12px / 16px    | 400, Mono      | 사진 캡션, 정보 3개, 태그      |
| 뱃지      | `text-badge`   | 11px / 14px    | 500, 자간 넓게 | 지역 뱃지                      |

- 제목 자간은 살짝 좁게(`-0.01em`), 뱃지는 넓게(`0.08em`). 나머지는 기본.
- 한 화면에 **굵기는 2개까지** (400 + 600). 700 이상은 쓰지 않는다.
- 첫 글자만 대문자 (Sentence case). 제목을 전부 대문자로 쓰는 건 뱃지만.

### 2-3. 여백

기준 단위 4px. 실제로 쓰는 값은 아래 6개만.

| 이름  | 값   | 어디에                               |
| ----- | ---- | ------------------------------------ |
| `xs`  | 4px  | 글자 사이 아주 좁은 틈               |
| `sm`  | 8px  | 캡션과 사진 사이, 태그 사이          |
| `md`  | 16px | 카드 안 여백, 화면 좌우 여백         |
| `lg`  | 24px | 카드와 카드 사이                     |
| `xl`  | 40px | 구역과 구역 사이 (소개 글 ↔ 정보 표) |
| `2xl` | 64px | 페이지 맨 아래 버튼 위               |

화면 좌우 여백은 폰에서 16px, PC에서는 내용 폭을 **최대 640px**로 잡고 가운데 놓는다.
(PC에서 카드를 3열로 펼치지 않는다. 사진집은 넓게 펴지 않는다.)

### 2-4. 모서리·테두리·그림자

| 항목   | 규칙                                               |
| ------ | -------------------------------------------------- |
| 모서리 | 사진·카드·버튼 전부 **4px**. 입력 칸 4px. 뱃지 2px |
| 테두리 | 1px, 색은 `line`. 카드·입력 칸·보조 버튼에만       |
| 그림자 | **없음.** 어디에도                                 |
| 구분선 | 1px `line`. 정보 표 줄 사이, 발(Footer) 위         |

모서리를 12px, 16px, 24px로 둥글게 하면 "앱 템플릿"처럼 보인다. 4px는 "모서리를 살짝 다듬었다" 정도다.

### 2-5. 아이콘

- 쓰는 곳: 뒤로 가기 화살표(←), 외부 링크 표시(↗), ★ 딱 세 개.
- 나머지는 글자로 해결한다. "Time", "Price"처럼 글자 앞에 시계·돈 아이콘을 붙이지 않는다.
- 이모지는 어디에도 쓰지 않는다.

## 6. Tailwind 설정에 넣을 이름 (정리)

문서 작성용으로 이름만 정리한다. 실제 코드는 개발 1주차에 쓴다.

```text
색
  paper       #FFFFFF
  ink         #1C1C1A
  ink-press   #333330   (큰 버튼 눌림에만)
  ink-soft    #6B6B66
  line        #E6E4DF
  accent      #1F4E5F
  error       #B4382A   (이메일 오류에만)

폰트
  display     Bricolage Grotesque
  sans        IBM Plex Sans
  mono        IBM Plex Mono

글자 크기 (크기 / 줄간격)
  display     40 / 44
  title       26 / 32
  card        19 / 24
  body        16 / 26
  small       14 / 20
  caption     12 / 16
  badge       11 / 14  (자간 0.08em)

여백
  xs 4 · sm 8 · md 16 · lg 24 · xl 40 · 2xl 64

모서리
  기본 4px · 뱃지 2px

그림자
  없음 (첫 화면 사진 위 글자 그림자만 예외)

내용 최대 폭
  640px

사진 비율
  첫 화면 세로 전체 · 카드 4:5 · 상세 추가 3:2 · 작은 카드 1:1
```
