## 5. "AI가 만든 사이트" 티 없애기 — 금지 목록과 대안

요즘 AI가 만든 사이트는 서로 닮았다. 아래는 그 공통 특징과, 이 사이트에서는 대신 어떻게 하는지다.
개발하면서 화면이 이상하게 "익숙하다"고 느껴지면 이 표를 다시 본다.

| 번호 | AI 티 나는 것                                                                           | 왜 티가 나나                         | 이 사이트에서는                                              |
| ---- | --------------------------------------------------------------------------------------- | ------------------------------------ | ------------------------------------------------------------ |
| 1    | 그라데이션 배경·버튼·글자                                                               | 2023~25년 AI 생성 사이트의 대표 특징 | 단색만. 색은 4개                                             |
| 2    | 보라·파랑 조합, 네온 강조                                                               | 기본 템플릿 색                       | 쪽빛 하나                                                    |
| 3    | 크림 배경 + 세리프 제목 + 주황 강조                                                     | 최근 AI가 "세련됨"으로 학습한 조합   | 순백 + 고딕 + 쪽빛                                           |
| 4    | 유리처럼 비치는 카드 (blur, 반투명)                                                     | 효과로 내용 부족을 가림              | 흰 카드, 1px 선                                              |
| 5    | 그림자 층층이, 카드가 둥둥 뜸                                                           | "입체감"을 흉내 냄                   | 그림자 없음                                                  |
| 6    | 모서리 16~24px                                                                          | 앱 UI 키트 기본값                    | 4px                                                          |
| 7    | 항목마다 아이콘, 원 안에 아이콘                                                         | 내용 없이 칸을 채움                  | 아이콘 3개만 (← ↗ ★)                                         |
| 8    | 이모지 제목 (🌊 Sea & islands)                                                          | 채팅처럼 보임                        | 없음                                                         |
| 9    | 큰 숫자 + 작은 설명 3개 나란히 ("40+ Experiences / 2 Regions / 100% Free")              | 랜딩 페이지 템플릿                   | 없음. 숫자로 자랑하지 않는다                                 |
| 10   | 숫자 매긴 단계 (01 / 02 / 03) 장식                                                      | 순서가 없는데 번호를 붙임            | 질문 진행 표시(1/3)에만. 여기는 진짜 순서다                  |
| 11   | 화면 들어올 때 스르륵 나타나는 애니메이션                                               | "부드러움"의 흉내                    | 애니메이션 없음 (PRD 안 만드는 것)                           |
| 12   | 마우스 올리면 카드가 커지고 떠오름                                                      | 폰에서는 마우스가 없다               | 테두리 색만 바뀜                                             |
| 13   | 뻔한 문구: "Discover the magic of Korea", "Unlock your journey", "Curated just for you" | 광고 문장                            | 짧고 구체적으로: "Seoul is 1% of Korea." "Takes 20 seconds." |
| 14   | 사진 위 어두운 반투명 막                                                                | 아무 사진이나 쓰려고 덮음            | 막 없음. 사진을 고른다                                       |
| 15   | AI 생성 사진, 스톡 미소 모델                                                            | 손·글자가 이상하고 어디서 본 얼굴    | 실제 장소, 실제 시간                                         |
| 16   | 여백이 균일하게 넉넉하기만 함                                                           | 리듬이 없어 어디가 중요한지 모름     | 사진은 크게(꽉), 글은 촘촘히. 대비를 둔다                    |

| 22   | 발(Footer)에 4열 링크 묶음                                                              | 큰 회사 사이트 흉내                  | 링크 3개 한 줄                                               |
| 23   | 로고가 원형 아이콘 + 글자 조합                                                          | AI가 만든 로고 공식                  | 글자 로고만 (사이트 이름 결정 후)                            |
| 24   | 모든 카드·구역 높이가 정확히 같음                                                       | 내용을 잘라서 맞춤                   | 글 길이만큼 카드가 늘어난다                                  |

### 이 문서 자체를 점검하는 방법

디자인이 끝나면 아래 질문에 답한다.

1. 이 사이트에서 사진을 전부 빼면 뭐가 남나? → **거의 아무것도 안 남아야 정상**이다. 남는 게 많으면 장식이 많은 것이다.
2. 스크린샷을 찍어서 다른 여행 사이트 옆에 놓았을 때, 어느 게 우리 것인지 바로 알겠나? → 캡션(`Jumunjin · 05:40`) 때문에 알아야 한다.
3. 화면에서 하나를 뺄 수 있나? → 있으면 뺀다.
