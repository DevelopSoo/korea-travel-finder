# 기획 문서 참조

구현 전에 아래를 **필요한 부분만** 읽는다.

1. `docs/product/index.md` — 기능 목록과 각 문서의 위치. 항상 여기부터.
2. 지금 구현할 기능에 해당하는 문서 1~2개만 읽는다.

## 규칙
- 기획서에 명시된 요구사항 범위를 임의로 넓히거나 좁히지 않는다.
- 기획서에 없는 케이스(빈 상태, 에러, 권한 등)를 만나면 임의 결정 대신 짧게 확인한다.
- 구현 후에는 해당 기능의 완료 조건을 기획서 기준으로 점검한다.
