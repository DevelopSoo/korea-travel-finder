# 디자인 시스템 참조

UI 작업 전에 아래를 **필요한 부분만** 읽는다. 전체를 통째로 읽지 말고 목차/헤딩으로 해당 섹션을 먼저 찾는다.

1. `docs/design-system/index.md` — 목차. 항상 여기부터 읽는다.
2. 목차가 가리키는 개별 문서 중 **지금 작업에 해당하는 것만** 읽는다.
   - 예: 버튼 작업 → `docs/design-system/components.md` 의 Button 섹션만
   - 예: 색상 결정 → `docs/design-system/tokens.md`

## 규칙
- 토큰에 정의된 값이 있으면 임의의 하드코딩 값(`#3b82f6`, `mt-[13px]`)을 쓰지 않는다.
- 정의되지 않은 값이 필요하면 임의로 만들지 말고 사용자에게 한 줄로 확인한다.
- 문서와 실제 코드가 충돌하면 문서를 신뢰하되, 충돌 사실을 알린다.
